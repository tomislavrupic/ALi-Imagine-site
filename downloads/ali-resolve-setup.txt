ALi Resolve skill 1.1.0 / ALi Imagine MCP

1. Install ALi Imagine 0.9.18+, launch it, and open DaVinci Resolve.
2. Enable Resolve external scripting access.
3. Unzip ali-resolve-skill-1.1.0.zip and install the entire ali-resolve folder
   into ~/.agents/skills/ali-resolve, retaining scripts and backing up an older copy.
4. Register the app-installed MCP client:

   codex mcp add ali-imagine -- python3 "$HOME/Library/Application Support/ALi-Imagine/mcp/server.py"

5. Reopen the Codex chat. Ask $ali-resolve to check both connections without
   generating media or changing the timeline. Read README.md and SKILL.md.

MCP runs on authenticated loopback 17843. Resolve bridge uses 17841. No
credentials go into the skill or MCP configuration. Python 3 is required.
Models are installed separately. Inspect engine status before generation;
H3 is authorization-gated in public builds. Whole-number timeline fps only.
Do not blindly retry a timed-out generation; reconcile persisted job IDs.

The ZIP contains the skill and all helper scripts; no apps, models or media.
Verify the ZIP with its matching .sha256 file before installing.

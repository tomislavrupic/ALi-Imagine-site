# ALi Imagine v0.8.2

Version 0.8.2 removes the LTX 2.5 Signal Test as a hard installation and generation requirement.

- LTX is ready in Create after the isolated runtime is verified and the pinned model components are present.
- The Signal Test is optional diagnostics and is no longer shown as a blocking setup step.
- Optional deep model verification remains available from the LTX installer panel.
- Existing package/runtime fixes from v0.8.1 remain included.
- Other local engines retain their existing certification requirements.

# ALi Imagine v0.8.0

Version 0.8.0 makes ALi easier to install and smarter to prompt across the complete visual pipeline.

- Adds model-aware Prompt Assist for xAI Grok Imagine, Krea 2, FLUX.2, MiniMax H3, and LTX 2.5.
- Supports Prompt Assist for text-only video as well as source-frame workflows.
- Automatically selects the appropriate text-video or image-video path from the supplied sources.
- Adds guided, app-managed installation for local model dependencies, including Qwen prompt-assistance support.
- Installs and launches the DaVinci Resolve integration with the ALi app.
- Shows live LTX render phases, progress, and transferred data while jobs run.
- Preserves existing projects, models, originals, audio, lineage, and certifications.

## macOS installation

1. Download the Apple Silicon DMG.
2. Drag ALi Imagine to Applications.
3. On first launch, Control-click ALi Imagine and choose **Open** if macOS prompts you.
4. Enter the studio immediately or follow the guided local-engine setup.

# ALi Imagine 0.9.41

Looks can now use original reference images directly with Qwen, without requiring a trained LoRA. Choose and order up to ten references in the main Concepts image grid; selections save automatically, including an explicitly empty selection. The combined limit includes source images and references from other Looks. Qwen may borrow subjects and composition as well as style, so reference selection matters.

The Looks library shows one card per reference Look, uses selected references for its cover, and avoids repeating represented style adapters in FX. Stored adapters and their review states remain available in Concepts.

Qwen native 2× now accepts inherited Look continuity metadata while retaining source identity and dimension checks. A real 1344×768 to 2688×1536 render completed with the original source checksum preserved.

Includes the Concepts training and review workspace, reference caption analysis, final checkpoint recovery, aspect-preserving training preprocessing, a reference training recipe for new runs, and stronger adapter comparison receipts. Technical certification remains separate from creative approval. Earlier trained styles showed weak resemblance in testing; direct references produced stronger visual influence but do not isolate style perfectly.

No broad MLX dependency upgrade or new model download is included. Existing model access and license requirements remain unchanged. Signing, notarization, updater verification and public publication are recorded separately in the release receipt.

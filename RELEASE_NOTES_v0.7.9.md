# ALi Imagine v0.7.9

Version 0.7.9 fixes the LTX 2.5 Native MLX installer button appearing to do nothing.

## Fixed

- The runtime installer begins directly when its explicit install button is pressed.
- Removed the browser-style confirmation that could remain invisible in the macOS app window.
- The setup screen immediately reports that the Native MLX runtime installation is starting.
- The separate confirmation for the large LTX 2.5 model pack remains in place.

## Installation

1. Download the Apple Silicon DMG.
2. Drag ALi-Imagine to Applications.
3. Control-click the app and choose Open once if macOS prompts you.
4. Press **Install LTX-2.5 Native MLX Runtime**. The starting state should appear immediately.

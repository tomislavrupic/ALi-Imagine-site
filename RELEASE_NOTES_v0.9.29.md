# ALi Imagine 0.9.29

FX LoRAs now attach their settings to Create and reuse the existing video source well. The extra Restore, Refine, Alpha and Layout mode buttons have been removed. Choose **Use** in FX, add your source, adjust the LoRA settings and Generate Video. Change and Remove controls stay beside the LoRA settings; removing the LoRA preserves its source video.

- Fixed engine switching and stale LoRA notices. Readiness refreshes no longer reset the current draft.
- LTX generation defaults to **Large, Best delivery, 8 + 3 steps** and **Start Frame** for Image Video. Image Video and First + Last use Source aspect; Text Video uses 16:9.
- Duration sits directly below Signal, before the video output settings, including Audio Video.
- Restore and creative upscale retain separate **2-step defaults**. Reopening an unrelated take no longer changes those settings. Saved requests retain their recorded sampling settings.
- Gallery videos and imported video sources use the existing source wells. FX cards no longer advertise video drop targets.

Original media, existing queue records and model installations are preserved. Public H3 execution remains authorization-gated; the separate local private H3 installation is not distributed through the public updater.

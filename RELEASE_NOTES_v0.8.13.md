# ALi Imagine v0.8.13 Preview

Version 0.8.13 makes long local work easier to trust, recover, and organize.

- Active renders remain visible in Recent Outputs with live progress and an explicit Cancel / Override action.
- Interrupted LTX 2.5 upscale state is recovered after restart instead of blocking new work indefinitely.
- Remove from Library now hides an output without deleting its media file. The separate Trash action remains explicit.
- Native LTX 2.5 spatial 2× accepts short or missing source audio, preserving available audio and filling only the missing tail with silence.
- Stage playback starts at 20% volume, System paints immediately before slower diagnostics, and long status copy is reduced.
- The interface receives a restrained blue-first palette, smoother gradients, and clearer render-state animation.
- Versioned experimental IC-LoRA Union Canny and LipDub v0.9 compatibility paths passed isolated local acceptance renders with pinned provenance.

Advanced LTX 2.5 Retake, Extend, and multi-keyframe Warp remain an explicit local-model acceptance track. Their large Q8 model is a separate resumable download and is not bundled in this DMG.

This preview is ad-hoc signed and not yet Apple-notarized. macOS may require Control-click → Open once after installation.

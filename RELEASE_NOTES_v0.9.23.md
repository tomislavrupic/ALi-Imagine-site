# ALi Imagine 0.9.23 — Readable controls and direct result selection

Click a completed clip to open Result immediately, even while another clip is rendering. Percentage and denoising steps remain visible below the stage.

H3 denoising, Reset and Delivery controls now match the compact technical typography of the rest of the studio. Current and queued render cards keep machine, elapsed time and prompt above a separate Stop button. Recent Outputs has separate heading and navigation rows. Playback, stage actions and the network icon beside System fit compact windows.

Update the laptop through the update icon. Private H3 Studio installations require the matching private build, preserving H3 and the existing public-updater guard. Pairing, models, recipes, projects, MCP and Resolve workflows are retained.

Validation: 251 frontend tests; 517 Rust tests (81 hardware/opt-in tests ignored); formatting, Clippy and production build. Actual App browser fixtures cover selection during rendering, progress and layouts through the minimum 900×680 window. These are UI checks, not native inference. Public artifacts are Developer ID signed, Apple notarized, signature verified and extracted with the updater's path handling.

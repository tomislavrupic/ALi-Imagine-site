# ALi Imagine v0.8.3

Version 0.8.3 repairs recoverable asset trash, adds Stage playback volume, and completes the guided Qwen Prompt Assist installer.

- Qwen Prompt Assist now has its own visible System section.
- One action prepares the private Python and Prompt Assist runtimes, downloads the pinned public Qwen 3.8 model, verifies it, and activates it locally.
- The installer shows live phase, percentage, and transferred GiB, supports Cancel, and resumes preserved partial downloads after cancellation, interruption, or app restart.
- Qwen requires neither an xAI key nor a Hugging Face token.
- Recent Outputs and Library Move to Trash actions now execute directly into reversible Project Trash with visible progress and actionable errors.
- Stage playback now includes a persistent volume slider beside mute.
- Existing LTX 2.5 installation and generation behavior remains unchanged.

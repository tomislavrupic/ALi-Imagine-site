# ALi Imagine 0.9.40

Completes the 0.9.40 previews and fixes stale Gallery results after the last background render finishes. Completed outputs refresh even when another queue call remains busy or an older project read is still in flight.

- CEL Character Steps slider: 2–60, default 30.
- Optional LTX brightness stabilization and native 2× join exposure matching, off by default.
- Explore LTX Orbit uses a single starting image and correct Fit framing. Orbit remains experimental: reliable full 360° coverage and frozen geometry are unverified. Review side and back views before building 3D.
- Includes Qwen Turbo, Full and Unlocked, Qwen 2×, Refine, raw prompting, FLUX 3, Explore, and existing image/video workflows, MCP, Resolve and paired-Mac rendering.

The eight-step CEL comparison was cancelled; it does not establish quality or speed. Qwen models use the noncommercial Qwen Research License. FLUX requires separate Hugging Face access and setup. Public H3 execution remains authorization-gated. No model downloads are included.

Apple-silicon macOS app, Developer ID signed and Apple notarized. Includes the signed updater archive and checksums.
